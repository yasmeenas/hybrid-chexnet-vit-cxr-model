# Hybrid CNN-ViT Model for Chest X-Ray Classification and Interpretation
Intro. CV Final Project Yasmeen Shabazz

original ChexNet paper: Rajpurkar et al. CheXNet: Radiologist-Level Pneumonia Detection on Chest X-Rays with Deep Learning https://arxiv.org/abs/1711.05225

Hybrid Model Combines CheXNet and ViT

- Attention Rollout: ViTs
- Ablation-CAM: hybrid model
